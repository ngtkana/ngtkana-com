# ながたかな 公式ウェブサイト

歌い手「ながたかな」のプロフィールサイト。Astro製の静的サイトとして構築し、Google Cloud Run にデプロイしている。

- **URL**: https://ngtkana.com

## セットアップ

```sh
npm install
npm run dev
```

Node.js 22 系を前提とする（CI・Dockerfile と揃える）。
